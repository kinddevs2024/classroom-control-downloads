**Пилотная версия 0.3.2 для Windows 10/11.**

## Начало работы

1. Распакуйте архив учителя в постоянную доступную для записи папку и запустите Classroom.Teacher.exe.
2. На ученике закройте 0.2, распакуйте новый архив целиком и запустите Classroom.Student.exe. Классы и профили создавать не нужно.
3. Ученик появится в списке. Выберите его и нажмите «Разрешить управление».
4. На ученике один раз подтвердите доступ учителю, сверив короткий код с его «Справкой».
5. «Экран и управление» открывает изображение основного монитора; флажок в этом окне включает передачу мыши и клавиатуры.

Есть блокировка рабочего стола с текстом, разблокировка, сообщения, настраиваемые сайты, информация о текущем пользователе и завершение сеанса. Галочки и «Весь класс» задают область групповых команд. Автозапуск ученика включается в его окне. Обнаружение — UDP 47832; команды — TLS/TCP 47833 на ученике.

## Обновления

Учитель проверяет подписанные пакеты при запуске и каждые 10 минут:

- [Student-latest.ccupdate](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Student-latest.ccupdate)
- [Teacher-latest.ccupdate](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Teacher-latest.ccupdate)

Ученический пакет передаётся старым разрешённым клиентам, учительский устанавливается на учителе. Проверяются подпись RSA/SHA-256, роль, версия и сумма. Предыдущий EXE сохраняется, при неподтверждённом запуске новой версии выполняется восстановление. Первая установка 0.3 вместо 0.2 — вручную. Закрытые ключи в этом репозитории отсутствуют.

## Что важно при испытании

Это пилотная пользовательская версия, не служба SYSTEM. Не управляет экраном входа и UAC; учебная блокировка сохраняет Ctrl+Alt+Del, аварийное снятие — Ctrl+Alt+F12. При потере связи блокировка снимается примерно через 30 секунд. Для второго учителя требуется отдельное однократное разрешение ученика; текущая сессия управления имеет одного владельца.

Фильтр сайтов действует в браузерах с системным прокси Windows. Реальный Chrome проверен; Edge отдельно не проверен. HTTPS не расшифровывается. Существующий сторонний прокси/PAC не подменяется, VPN и собственные прокси приложений могут обходить фильтр. Настройки сети восстанавливаются при снятии фильтра/выходе и модулем NetworkGuard после аварии.

Между разными сетями необходим доступный маршрут, например VPN; после него есть «Подключить по IP». Программа не создаёт VPN. Требуется .NET Framework 4.8. В архиве есть подробная инструкция.

Проверены защищённый канал, настоящий экран и ввод, блокировка, переключение разрешённого владельца, сетевой фильтр, обновление обоих EXE и возврат предыдущего файла при неудачном запуске. Версия 0.3 ещё требует проверки на реальном втором ученическом компьютере и нагрузки 25–50 устройств; тесты на рабочем компьютере не заменяют такую приёмку.
