# Класс — управление учебными компьютерами Windows

Версия **0.4.0**, Windows 10/11, .NET Framework 4.8.

- [Скачать программу учителя](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Classroom-Teacher-0.4.0.zip)
- [Скачать программу ученика](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Classroom-Student-0.4.0.zip)
- [Выпуски и контрольные суммы](https://github.com/kinddevs2024/classroom-control-downloads/releases)

Распакуйте архив целиком в постоянную доступную для записи папку и запустите соответствующий EXE. Ученики обнаруживаются автоматически. Выберите их в учительской программе → «Разрешить управление» → один раз подтвердите доступ на каждом ученике.

Доступны экран и управление мышью/клавиатурой ученика, блокировка с текстом, сообщения, сайты, информация о пользователе, групповые команды. В 0.4.0 добавлены «Показать мой экран» в обычном окне у учеников, вставка буфера учителя и Ctrl+V в удалённом экране, а также передача файлов выбранным или всем компьютерам. Полученные файлы сохраняются в «Загрузки → От учителя», программы автоматически не запускаются. Один файл — до 1 ГБ.

Учитель при запуске и каждые 10 минут проверяет подписанные пакеты [Student-latest.ccupdate](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Student-latest.ccupdate) и [Teacher-latest.ccupdate](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Teacher-latest.ccupdate). Учитель обновляется сам и передаёт пакет разрешённым ученикам. Кнопка «Проверить обновления» запускает проверку сразу. Проверяются подпись, роль, версия и SHA-256; при неудачном запуске восстанавливается прежний EXE. Закрытых ключей здесь нет.

Обнаружение — UDP 47832; управление — защищённый TCP (обычно 47833, при занятости выбирается свободный). В другой сети нужен доступный маршрут/VPN, есть ввод IP:порт. При первом запросе брандмауэра доступ к школьной сети разрешает пользователь.

Это пользовательская программа, служба SYSTEM в этот выпуск не входит. Не управляет экраном входа, UAC и правами локального администратора. Экран передаётся около 2 кадров/с без звука. Фильтр сайтов использует системный прокси без расшифровки HTTPS; собственный прокси/VPN браузера может его обходить. Подробная инструкция в архиве.

Проверены настоящий экран и ввод, доступ, блокировка, передача файлов и буфера, показ экрана, подпись обновлений, установка обоих EXE с 0.3.2 и откат. Испытание на 25–50 физических устройствах ещё требуется.
