[Скачать Classroom-Student-0.2.0.zip](https://github.com/kinddevs2024/classroom-control-downloads/releases/download/student-v0.2.0/Classroom-Student-0.2.0.zip)

## Запуск на ученическом компьютере

1. Скачайте ZIP и полностью распакуйте его в отдельную папку.
2. Запустите **Classroom.Student.exe**.
3. Учительская программа версии 0.2 должна быть открыта на компьютере учителя в той же локальной сети.
4. Ученический компьютер должен появиться автоматически, обычно через 2–5 секунд. Создавать классы и переносить профили не нужно.

Целевая среда — Windows 10/11 с .NET Framework 4.8. Это переносимый прототип; установка службы и автозапуск отсутствуют.

Если компьютер не появился, проверьте разрешение для приложения в брандмауэре частной сети (UDP 47832) и отсутствие изоляции устройств Wi-Fi. Программа не меняет настройки брандмауэра автоматически.

Сейчас реализовано обнаружение компьютеров и выбор основного учителя. Просмотр экрана, удалённое управление, блокировка, фильтрация сайтов и автообновления пока не реализованы. Проверка на втором физическом компьютере ещё требуется.

В архив входят только EXE, конфигурация и инструкция. Рядом с архивом в выпуске доступен файл SHA256SUMS.txt.

Репозиторий закрытый: для скачивания войдите в GitHub под аккаунтом, которому предоставлен доступ.
