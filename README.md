# Класс — управление учебными компьютерами Windows

Учитель и ученик **0.5.0**, Windows 10/11, .NET Framework 4.8.

- [Скачать программу учителя](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Classroom-Teacher-0.5.0.zip)
- [Скачать программу ученика](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Classroom-Student-0.5.0.zip)
- [Выпуски и контрольные суммы](https://github.com/kinddevs2024/classroom-control-downloads/releases)

Распакуйте ZIP целиком в постоянную доступную для записи папку. Ученики обнаруживаются автоматически. Для первого доступа выберите ученика → «Разрешить управление» → подтвердите запрос на ученике. Для сетей с VPN есть IP:порт. Закрытых ключей и пользовательских профилей в репозитории нет.

Доступны экран и ввод, «Все экраны», показ учителя, сообщения, блокировка с текстом, сайты, файлы, текстовый буфер. В 0.5.0 ученик продолжает связь после «минуса» и крестика в фоне без трея и кнопки панели задач. На старте и блокировке есть явное уведомление об управлении учителем. Ctrl+Alt+F11 или повторный запуск EXE открывает сведения. Это обычный видимый системным средствам процесс.

Блокировка ученика 0.5.0 сохраняется при потере связи, закрытии и после повторного входа Windows/старта клиента. Разблокировка и штатный выход доступны доверенному учителю; локально — по паролю обслуживания. Пароль задаётся учителем, исходного пароля нет. Ctrl+Alt+F12 открывает обслуживание. Для администратора Windows предусмотрено отдельное восстановление с UAC: оно останавливает клиент, после него клиент нужно запустить в учётной записи ученика снова. Автозапуск/состояние пользовательские, до входа в Windows компонент не действует; противодействия администратору и службы SYSTEM нет.

В «Все экраны» есть масштаб Ctrl +/−, кнопки и ползунок: минимум — все плитки, максимум — 2×2 с прокруткой остальных, Ctrl+0 возвращает общий обзор. Пропорции изображения сохраняются. Проверены 25/50 плиток на типичных размерах окна; чтение всех 50 на маленьком мониторе одновременно не обещается.

Учитель при запуске и каждые 10 минут проверяет [Student-latest.ccupdate](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Student-latest.ccupdate) и [Teacher-latest.ccupdate](https://github.com/kinddevs2024/classroom-control-downloads/releases/latest/download/Teacher-latest.ccupdate). Кнопка «Проверить обновления» запускает проверку сразу. Подпись, роль, версия и SHA-256 проверяются; прежний EXE сохраняется и восстанавливается при неудачном запуске. Обычное обновление может перезапустить приложения. При первом переходе с 0.4.x старую блокировку, хранившуюся только в памяти, после обновления следует задать заново.

Файлы сохраняются в «Загрузки → От учителя», не запускаются автоматически. Fliqlo не установлен: в ZIP учителя есть только read-only Inspect-Fliqlo.ps1 и инструкция для пяти минут, требующие конкретного проверенного файла и совместимости ОС.

Тесты выполнены в изолированных локальных фикстурах: поток/UDP/ввод после минимизации, закрытие и повторное подключение, сохранение блокировки между процессами, подписанный update с восстановлением lock, защищённый канал, 50 TLS-источников, масштаб и раскладка. Реальные перезагрузки Windows, UAC с отдельным администратором, DPI и 25–50 физических ПК ещё требуют приёмки. Подробности/откат — RELEASE-0.5.0.ru.md в архивах.
